# DDTank Bot

Bot visual automático para DDTank usando Python + OpenCV.

## Funcionalidades

- Auto farm
- Reconhecimento visual
- Auto repetir dungeon
- Detecção de batalha
- Auto ataque

## Tecnologias

- Python
- OpenCV
- PyAutoGUI
